# Conceptual Design

- what the reader should know
  - fully formulated problem
  - fully decomposed conceptual solution
  - specifications for each piece of the solution
  - additional constraints and their origins
  - how team will accomplish their goal with available resources
- introduce and restate the problem
  - ask if anything should be added
  - should anything be removed
  - applies to specifications and constraints
- comparative analysis
  - possible approaches to solving the problem
  - quantitative and qualitative solns -> compare
  - are there aspects that make certain ideas non-starters?
  - do the benefits justify the cost of the solution
    - ie. is the more expensive option better?
  - pick the solution that will **most** likely to succeed.
- high-level solution
  - maximize stakeholder goal attainment (achieves the goal)
  - adhere to established constraints
  - minimize risks
  - optimize resource utilization
- hardware block diagram
  - name and brief of explanation for each block
    - ex) Microcontroller: Takes in user input and determines when to tun on the toaster heating element
  - concise description of each
- operational flow chart
  - specify the system from users point of view
  - outline the steps a user should take to use device
  - each step represented in the diagram to visually depict the sequence of action the user will encounter
- breaking down the problem
  - decompose solution into smaller subsections
  - each member presents a solution for at least one of the subsections
- atomic subsystems specifications
  - comprehensive description of the functions each subsystems
  - include a description of the interferences between this subsystem and other subsystems
    - include type of signal (power, analog signal, serial communication, wireless communication)
    - clearly define direction of the signal(input of output)
- ethical, professional, and standards considerations
  - what ethical situations do you expect to encounter
  - broader impacts on the community?
  - how do identify standards apply?
  - discuss how these standards have influenced the design of our project
- resources
  - create a budget by estimating the amount of money required to build each subsystem
  - appoint a designer for each subsystem
  - add detail to timeline
  - what critical unknowns need to be addressed early
  - does anything need to be prototyped
- overview check list:
  - describe fundamental engineering principles. math models, and tools used to analyze potential solutions
  - state at least one public health, safety, or welfare concern?
  - more in slides located on canvas
